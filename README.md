# TLauncher UX Research

Учебный проект, выполненный в ходе обучения.

## О проекте

Цель проекта — проанализировать пользовательский опыт TLauncher и выявить основные проблемы интерфейса.

В рамках работы были проведены пользовательские интервью и рассмотрены основные сценарии взаимодействия с приложением.

## Что анализировалось

- удобство главного экрана;
- поиск и установка модов;
- работа с версиями;
- понятность ошибок;
- навигация;
- удобство для новых пользователей.

## Основные выводы

По результатам интервью было выявлено, что пользователи считают TLauncher полезным и функциональным продуктом, но отмечают ряд UX-проблем:

- перегруженный интерфейс;
- устаревший визуальный стиль;
- слабая заметность важных действий;
- сложности при поиске модов;
- непонятные сообщения об ошибках;
- недостаточная поддержка новых пользователей.

При этом пользователи ценят возможность быстро запускать Minecraft, выбирать версии и работать с модами. :chatgpt-content-reference{index="0"}

## Рекомендации

По результатам анализа были предложены следующие улучшения:

- упростить главный экран;
- сделать ключевые действия более заметными;
- улучшить сообщения об ошибках;
- добавить более понятную обратную связь;
- обновить визуальный стиль интерфейса. 

## Материалы проекта

- Excel-файл с результатами интервью;
- Word-документ с анализом и выводами.

## Итог

Главный вывод исследования: TLauncher обладает полезным функционалом, но интерфейс требует упрощения и улучшения пользовательского опыта. Особенно заметны проблемы при поиске модов, работе с ошибками и первом знакомстве с приложением.
